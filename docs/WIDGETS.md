# Как виджет живёт в этой системе

Файл отвечает на вопрос «у меня есть готовый виджет — что с ним сделать».
Устройство ядра — `ARCHITECTURE.md`, план — `ROADMAP.md`, история решений —
`DECISIONS.md`. Деревня снята до портов (D-19) и вернётся уже по этим правилам.

## 1. Договор

Виджет — это **данные в мир и команды наружу**. Он не рисует.

- Живёт в Web Worker: нет DOM, нет Pixi, нет сети, нет `@tv/core`.
- Получает `WidgetEvent`: `Init`, `ViewerEvent`, `Viewport`, `Pause`, `Resume`,
  `Dispose`.
- Отвечает `RenderCommand` (дерево `CreateNode`/`SetParent`/`SetTransform`/…),
  упакованными в `Batch`, плюс `ServiceMessage`: `Ready` при старте и
  `Heartbeat` каждые 500 мс.
- Все сообщения — plain-объекты, сериализуемые `structuredClone`.
- Текстуры не грузит: ссылается на `assetId` из своего бандла.
- Время детерминировано: шаг мира получает `now`/`rng` извне, своего
  `Date.now`/`Math.random` в логике нет.

Три вещи, которые делает виджет в репозитории:

1. **Манифест**
   `WidgetDefinition { id, assetBundle, effectsManifest?, create(transport, ctx) }`.
2. **Worker-entry** — один файл: `self.onmessage` ↔ `Transport`, `Ready`,
   `Heartbeat`, `Pause`/`Resume`/`Dispose`, запуск тика.
3. **Слой «мир → команды»** — бывший `*-render.ts`: вместо мутации Pixi
   сравнивает предыдущее и текущее состояние и отправляет дельту.

Симуляция (ECS-системы, физика, баланс) остаётся как есть: она не знает про
рендер и в порт не входит.

## 2. Что умеет протокол сегодня

| Команда                                        | Покрывает                                            |
| ---------------------------------------------- | ---------------------------------------------------- |
| `CreateNode {nodeId, kind}`                    | контейнер, спрайт, текст                             |
| `RemoveNode`                                   | узел с поддеревом и фильтрами                        |
| `SetParent {nodeId, parentId, order}`          | иерархия и порядок                                   |
| `SetTransform`                                 | `x`, `y`, `scaleX/Y`, `rotation`, `alpha`, `visible` |
| `SetSprite {assetId}`                          | одна текстура                                        |
| `SetAnimation {assetIds, fps, loop}`           | покадровая анимация, `fps` дробный от 0.1            |
| `SetText {text, style{fontSize, fill, align}}` | подпись                                              |
| `SetTint {tint \| null}`                       | цвет содержимого узла                                |
| `AddFilter`/`RemoveFilter`/`SetFilterParam`    | фильтры по `effectId`, параметр — число или vec2-4   |

Пределы, о которые спотыкается любой готовый виджет: нет примитивов вместо
`Graphics`, нет масок, нет `TilingSprite`, стиль текста беден.

## 3. Аудит двух реальных виджетов

Оба — Pixi 8 + miniplex, рендер вынесен в `systems/*-render.ts`, грузят текстуры
через `Assets.load` по URL, манифеста ассетов нет.

| Что используется                               | Чем выражается                        | Пробел                |
| ---------------------------------------------- | ------------------------------------- | --------------------- |
| `AnimatedSprite` из листа                      | `SetAnimation` + нарезанные `assetId` | нет — нужен assetpack |
| `view.tint`, цвет по состоянию                 | —                                     | команды нет           |
| `Graphics`: плашки, HP, полоски времени, точки | `rect` + `SetTransform`               | примитива нет         |
| `Text` с обводкой, жирным, семейством          | `SetText`                             | стиль беден           |
| Свои шейдеры (aura, shield, overcharge)        | `AddFilter` + параметры               | нет vec2/vec3/цвета   |
| `TilingSprite` (пол)                           | спрайт под размер вьюпорта            | обход                 |
| Маска (бегущая строка)                         | —                                     | в v1 не переносится   |
| Слои сцены                                     | корневые контейнеры + `order`         | ок                    |
| Чат `@twurple` внутри страницы                 | события от Core                       | выносится             |

**`pizdudes-test`** (Pixi 8, ECS, ~40 файлов). Порт: манифест, worker-entry,
`systems/render.ts` → команды, лист повара в 64 `assetId` (8 направлений × 8
кадров), 13 станций по одному, пол спрайтом, бейджи через `rect`, `fps 15`.
Пакет `@tv/widget-pizdudes` собран и покрыт тестами; активируется в overlay
через общий манифест.

**`shooting-word-v2`** (SvelteKit + Pixi 8, ~180 файлов, но виджет — это
`src/lib/game/*` и `src/lib/vfx/*`). Пакет `@tv/widget-shooting-words` собран:
слова и корабли через `rect` + `SetText`, HP и полоски как квады, 217 кадров 20
скинов из assetpack, тесты на `DirectTransport`. VFX (`aura`, `shield`,
`overcharge`, `coating`, `shimmer`) в v1 не перенесены: компилятор эффектов не
подключён. Сервер (авторизация, раунды, награды, SQLite) в виджет не входит. В
overlay включается через общий манифест вместе с pizdudes.

## 4. Порядок порта

1. Завести пакет `@tv/widget-<имя>`: `package.json` с `exports` на `./worker`,
   `tsconfig` от общего, зависимости `@tv/protocol` и всё, что нужно симуляции.
2. Вынести слой рендера в модуль «мир → команды»; всё, что зовёт `pixi.js`,
   удалить из пакета, а не оставить за флагом.
3. Собрать манифест ассетов: `assets/` + `.assetpack.js`, бандл на виджет, ключи
   `assetId` — константами рядом с виджетом.
4. Написать worker-entry: `Ready` → тик из `setInterval` → `Heartbeat` →
   `Pause`/`Resume`/`Dispose`.
5. Прогнать на `DirectTransport` в Node: события → ожидаемые команды, без
   воркера и без Pixi.
6. Подключить в overlay и посмотреть в OBS.

## 5. Как проверять, что порт честный

- `grep -r "pixi.js" packages/widget-<имя>/src` пустой, линт границ зелёный.
- Ни одного `Texture.from`/`Assets.load` в пакете виджета.
- Команды декодируются `WidgetToCoreSchema` — тест на каждом сгенерированном
  сообщении.
- За тик нет команд для сущностей, которые не менялись.
- 200 сущностей, 100 тиков — кадр укладывается в бюджет, сообщение — в лимит
  размера.
- Остановка (`Pause`) даёт ноль команд за 5 секунд.
